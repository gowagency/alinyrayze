# Aliny Rayze — Repositório de Marca

Este repositório guarda o **guia de marca** e os **ativos visuais** da psicanalista Aliny Rayze, extraídos do site oficial https://alinyrayze.com.br/, para uso consistente em qualquer criação futura (redes sociais, peças impressas, slides, e-mails, materiais editoriais).

## Ponto de partida

Leia primeiro: **[`brand/brand-guide.md`](brand/brand-guide.md)**

## Estrutura

```
brand/
├── brand-guide.md     ← guia completo (cores, tipografia, voz, fotografia, copy)
├── logo/              ← logo SVG + favicon
├── fonts/             ← Averes Title Roman + Raleway (.ttf)
├── photos/            ← retratos e imagens oficiais
├── icons/             ← SVGs decorativos
└── reference/         ← snapshot HTML/CSS do site para consulta técnica
```

## Resumo executivo

- **Marca:** Aliny Rayze — Psicanalista
- **Tagline:** *Existe um jeito mais claro de viver.*
- **Paleta:** sage `#A1AF9E` · cream `#F7F6F2` · bege `#E8DCC9` · taupe `#8C7464` · forest `#4E6E47`
- **Tipografia:** Averes Title Roman (display) + Raleway (corpo) + Auraluxe Script (acento)
- **Tom:** sereno, maduro, direto, sem motivacional raso. Frases curtas, ritmo respirável.
- **Público:** mulheres adultas, fortes por fora, cansadas de viver reagindo.

Para qualquer peça nova, comece pelo checklist no fim de `brand/brand-guide.md`.
